# 雪峰滑雪租赁管理系统

> 本科《系统分析与设计》与 MBA《管理信息系统》课程教学案例  
> 当前版本：第一版单机教学演示系统（开发中）

## 项目简介

本项目将滑雪租赁企业案例中的业务需求、数据表和业务规则，转化为一个可以实际运行的网页管理系统，用于演示从需求分析、数据设计、系统设计到 AI 辅助实现与验收的完整过程。

项目使用 **WorkBuddy + 国产大模型** 辅助开发。目前先实现无需云服务器即可运行的单机教学版，业务数据保存在浏览器 `localStorage` 中；后续可按系统设计文档迁移到 CloudBase PostgreSQL 等集中式后端。

所有人物、门店、合同及业务数据均为虚构内容，仅用于课堂教学。

## 已实现的业务流程

### 租赁流程

1. 店员或管理员选择客户与在库设备创建合同。
2. 合同保存时固化设备日租金快照并将设备改为“借出中”。
3. 租赁期间可进行换货，系统按剩余天数和合同价格快照计算补收或退款。
4. 支持部分归还、批量归还和跨门店归还。
5. 所有有效明细归还后，合同自动转为“已完成”。

### 维修流程

1. 管理员或店员为在库设备创建维修单。
2. 系统按申请日期冻结承包商当时的小时费率，并将设备改为“维修中”。
3. 被分配的承包商只能查看和处理自己的维修单。
4. 维修完成时按冻结费率与维修工时计算成本，设备恢复为“在库”。

### 环境要求

```bash
cd app
npm install
npm run dev
```

```bash
cd app
npm run build
npm run preview
```

## 数据说明

- 演示数据首次运行时写入浏览器 `localStorage`；
- 页面刷新后数据仍会保留；
- 可从右上角用户菜单选择“重置演示数据”，恢复内置种子数据；
- 若检测到本地数据损坏，系统会进入数据恢复页面；
- 当前不支持跨浏览器、跨电脑或多人共享数据。

## 当前版本边界

当前仓库用于展示教学案例的阶段性成果，不应被视为可直接上线的生产系统：

- 登录与权限为前端和服务层模拟，不构成真实安全边界；
- 没有云数据库、服务端 API、并发控制和审计日志；
- 数据仅保存在当前浏览器；
- 驾驶舱 KPI 与图表仍在开发计划中；
- 部分业务模块仍在进行独立边界审核与补漏。
